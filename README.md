# gh-dash

GitHub Personal Dashboard — built with Astro, React, Tailwind v4, and shadcn/ui.

## Stack

- **Framework**: Astro 7 (SSR with @astrojs/node standalone)
- **UI**: React 19 islands + Tailwind v4 + shadcn/ui
- **Data**: GitHub API (GraphQL + REST)
- **Caching**: Railway Redis (TBD)
- **Deployment**: Railway
